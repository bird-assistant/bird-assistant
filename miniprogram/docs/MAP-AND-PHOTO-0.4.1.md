## 首页变化

- 地图固定在共用页头与 Tab 栏之间。搜索、等宽筛选、定位和刷新有明确布局，不再使用 `53vh` 地图与页面底部留白。
- 聚合点用数字圆标；单条用定位针。取消常驻物种文字，点聚合点继续放大或查看同地点记录。
- 观察列表在有明确高度的独立 `scroll-view` 中分页，不滚动整页。打开同地点记录时显示该地点计数，关闭和晚到响应互不干扰。
- 底部区域摘要和出行入口组成操作区；在原生地图底部留出 36px，不覆盖原生署名区。宽窗口限制面板宽度，短窗口压缩为一行操作。
- 鸟种搜索可关闭；输入变化、关闭或页面隐藏后的旧搜索响应不再重新打开结果。保留地图查询的坐标系、隐私范围、日期/来源筛选与后端分页合同。
- 观察详情图片读取失败时收起媒体区域并显示文字提示；成功图片依据实际比例显示，避免固定大空框。

## 图片画框、裁剪与拉伸

| 操作 | 图片内容如何变化 |
| --- | --- |
| 裁剪填充 | 鸟的横纵比例保持；画框变形会改变可见区域 |
| 自由变形 / 拉伸画面 | 横纵轴独立缩放，鸟本身可变宽、变扁、变细或变高 |
| 锁定原图比例 | 恢复原图长宽比与裁剪填充 |
| 锁定当前比例 | 保留当前形状，之后同步缩放宽高 |

`photoFit` 与画框比例锁分开持久化。未写此字段的旧草稿继续按裁剪填充解释，包括旧的自由宽高草稿；不静默改变已保存作品。拉伸保留原图路径、原始宽高和已有取景参数，不改设备文件。打开取景工具暂时预览裁剪填充；取消恢复原来的拉伸，应用后切换为裁剪填充，可撤销。

编辑画布、版式预览与 Canvas 导出共用 `photoCrop` 的源矩形和目标尺寸。[裁剪/拉伸对照](design/photo-fit-0.4.1.png)由该函数的实际计算生成。
