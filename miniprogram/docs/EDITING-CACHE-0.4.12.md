# 0.4.12：草稿日期、跨次编辑记录与主动生成

2026-11-27（北京时间）。[English / 完整证据与精简复测](en/EDITING-CACHE-0.4.12.md)

用户已确认旧论坛草稿存在、可继续编辑，也能新建另一篇；手帐名称保留，牌组视觉目前可接受。新截图显示照片手帐概述和两条独立照片说明预览；不据此宣称全部事实／应用已验收。论坛关联卡图注被挤到右侧，照片AI入口仍自动填请求并直接生成；撤销重做仅在本次打开有效。原生日志新增两个Page自由数据Map克隆警告、__tmp__图片路径失败，以及缺完整堆栈的null promise。

草稿现在分别标明创建／修改时间，修改优先，缺失或同一修改时间再比较创建时间。旧创建时间没有记录就保持未知，不补造；后续编辑记录真实修改时间。

手帐与匹配的撤销／重做记录同次提交，跨关闭／编译恢复，每份最多缓存20步，并有共享350 KB历史预算；只裁剪旧编辑步骤，不为缓存删除现有手帐。新编辑会清除旧重做分支，快照不包含其他历史，避免递归膨胀。过去版本已经丢失的步骤无法补回。保留步骤独有的照片也会持久化，关闭检查点防止迟到旧保存覆盖新文字，空间／损坏失败保留现有资料。

手帐卡片与编辑器名称行有“删除”，确认后等待正在进行的保存，删除该手帐与编辑记录并清理对应AI建议；不删除原照片、其他手帐或已用于帖子的成品图。可选建议清理失败单独反馈。

“打开照片AI写作”与普通AI入口都为空输入、无自动请求；填要求并点击生成后才发送。原“写作记录”改为“AI建议记录”，解释载入只放回预览、不改原稿、不再生成；撤销重做属于画布编辑记录。论坛关联卡明确上下排布，照片编号在图片下面的独立全宽行，不被横向挤压。

失败Map／Set移到onLoad按页面初始化，修复自由数据克隆风险。临时照片保存后，编辑器、AI缩略图、素材列表、版式与编辑历史都更新为持久路径；回归按saveFile实际移动语义验证。不能把这些具体修复当作已定位所有原生鉴权／null根因，也不宣称找回已丢的旧临时文件。
