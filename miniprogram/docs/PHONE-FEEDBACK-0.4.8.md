## Qwen部署交接

公网journal suggestions404与trip-plan405是路由存在性证据，不是上游Qwen授权结论。维护者需把包含writing router的当前业务代码部署到活动业务进程，再核查共享凭据和workspace。具体只读检查与配置见源码仓库`backend/deploy/course/JOURNAL-WRITING.md`。

客户端分别说明：本地照片准备失败、业务路由未部署、业务会话失效、Qwen授权/模型未开通、请求格式不支持、限流或超时。控制台只记状态/安全错误码/requestId，不记录会话、照片或原文。模型实际授权及返回仍需自己的登录身份试一次文字、一次主动选择的照片请求；本轮没有代用后台管理员账号或付费调用。

## 多页与豆包的后续方案（待设计）

多页采用书册包含有序页面，每页延续现有可编辑文档、撤销与保存；旧单页可作为第一页迁移。先讨论每册页数/照片数和导出目标（逐页图片、PDF或两者），再实现有界内存的顺序导出、失败后重试及分享。现有单页PNG/相册保存/微信分享先在两台手机验收，不把图片生成组图当作可编辑书册。

豆包Seedream作为独立可选媒体生成能力：用户挑选参考素材/说明用途→业务后端调用→明确标注AI生成的预览→用户应用为背景/装饰或放弃。保留原始鸟图与观察事实，标题正文和页面排版继续可编辑。单独配置火山方舟服务/模型权限与额度，模型开关/费用边界确认后再实现，不因Qwen故障直接替换提供方。

官方依据（2026-11-26查阅）：[图片生成API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)、[图片生成教程](https://docs.volcengine.com/docs/ark/image-generation-tutorial?lang=zh)。支持文本和参考图生成/编辑；具体多图、组图、图层和透明输出能力随模型而异。本方案是项目判断，不代表已实测质量或费用。

## 下一轮只测这四批

1. **系统占用**：识别开启相机/录音/长按录像→松手、切Tab、锁屏/后台、返回；检查系统指示灯消失且无迟到素材。随后点3.5×等倍率、滑轨、点/滑收放。
2. **手帐恢复与导出**：旧手帐不丢；新建标题不继承；给照片说明加标题及三行正文→保存、退出、重开→导出PNG→检查三行都在、图片顺序与比例正确。再测保存相册/分享，取消与拒绝权限不损原稿。
3. **地图/论坛**：定位与系统地图比对、记录系统精度；聚合1/两位/五位数字居中；出行顾问仍标注大致区域；整卡进入帖、翻面参数能滑到底、保存按钮不移动；我的发布/收藏/图鉴推荐间距。
4. **服务就绪后**：维护者确认journal路由与capabilities后，再测一次纯文字和一次选图；公开视觉502、音频404分别跟进，不阻塞前三批。

每次只回传失败项、设备/动作/预期/实际；导出图与后台指示灯结果最有价值。源码和自动测试不替代此轮真机结果。
