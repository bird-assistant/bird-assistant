# 窗口布局与返回行为：0.4.21

依据当前应用窗口，不按手机品牌／DPR／英寸或“iPad一律双栏”。宽但很矮、分屏后很窄的窗口仍可单栏；纸张与照片不为填满宽度变形。

已实现随手记：宽≥860 CSS px且减去页头后高≥440 px双栏；次要列表280–352px，主编辑区占其余、至少420px。小窗口只显示列表或当前编辑。启用iPad／桌面窗口调整，笔记页手机自动方向；原相机／手帐尺寸监听保留，仍需真机旋转／键盘检查。

选择窗格不是新Tab，也不应无限push原生页面。宽笔记中首次返回退出编辑焦点、列表仍在，再次返回离页；手机语义相同。全局Tab只在明确的全局导航时变化。

笔记双模式均由有界窗格滚动，折叠不会换成外层页面滚动导致列表定位丢失。脏编辑在平台支持时启用离页保护；强制结束进程或不支持该API仍不能保证未存内存文字。作用于整个云副本的系统确认采用全局模态；任务内工具保留关闭、遮罩、标题拖动与独立内部滚动。物理铰链位置不靠机型猜测，有窗口分段／安全区信息后再结合真机处理。

38窗口包括用户原30个DevTools配置，另加四个iPad横窗、两个分屏、859／860边界。新增尺寸是工程情景，不冒充实机测量。源码投影只证适配，不证键盘、手势、相机方向或物理折痕。
