本轮根据 0.4.1 的 Windows 验证与页面反馈继续修改。保留团队 d59be67 的地图/名录/出行顾问与此前手帐能力；识别业务逻辑不在本轮范围。识别页 JSON 仅补本地页头注册，以移除全局组件注册。

## 反馈与实际行为

| 反馈 | 0.4.2 行为 |
| --- | --- |
| 记住地图位置和缩放 | 保存最近一次原生地图稳定后的中心与缩放；重新创建页面时恢复。缓存损坏或写入失败不阻断地图，不自动请求定位权限。 |
| 腾讯署名穿过观察列表 | 手机展开列表时缩短地图，在其下方显示独立列表；宽窗口改为左侧列表与右侧地图。原生署名留在地图内部，不隐藏或重绘。程序引起的地图尺寸变化不关闭列表，手动拖动/缩放可关闭并刷新。 |
| 鸟名搜索需要实时、有限高度 | 首页、对比页与回复鸟种建议共用防抖查询：空输入无选项；输入后约220ms查询；先精确/前缀匹配，再稳定排序。结果在有限高度内滚动并分页，编辑、关闭、隐藏后的旧响应失效。旧服务器没有分页标志时只展示首批，避免循环加载。 |
| 图鉴照片背景与加载状态 | 照片按原比例计算实际显示框，透明背景、细边框；有加载、失败重试与缺图状态。公开资料缓存5分钟、最多32项并合并并发请求；照片仍使用原有授权图片接口及HTTP缓存。保留署名/许可/原出处。 |
| 辨认页签不清楚 | 改为「图鉴／出现地点／相关讨论」。地点按名称、数量、日期分行；可继续加载。相关讨论显示该鸟种已审核帖子，并提供带鸟种话题的发帖入口。 |
| 对比列没有对齐 | 单鸟种居中并使用较宽卡片；多鸟种等宽列，最多3列可横向滑动。照片、署名、七项性状和来源分区高度一致，缺失值显示“—”。 |
| 装饰需要原比例锁 | 一个按钮锁定原始装饰比例，再点解除；宽度、角点拖动和边界限制共用该状态，可撤销并持久化。旧装饰保持自由宽高，照片已有的拉伸/裁剪不变。 |
| 论坛缺少常见交互 | 紧凑信息流显示作者、时间、标题/摘要、缩略图及赞／回复／收藏。刷新在顶部，并支持下拉刷新和继续加载。发帖使用完整标题/正文输入区及草稿、预览入口。 |
| 回复像孤立表单 | 详情有回复链、回复对象、审核状态及可附鸟种建议的正文框；失败保留正文、对象及幂等编号，修改内容后换编号。已审核回复可回复，待审核回复仅作者可见。每100条加载更早回复。 |

## 服务合同与兼容

- 继续使用现有 Python 业务服务、登录、审核和数据库；没有引入未配置的 `wx.cloud` 调用。后续云端工作应沿用该服务边界。
- 回复新增可空 `parentId`，只接受同帖已审核父回复；重试同时比较内容、鸟种和父楼层，跨帖/隐藏父楼层不可引用。旧 SQLite 仅新增可空 `parent` 列及索引，已有回复、审核和幂等记录保留。
- 信息流与详情返回公开赞数、已审核回复数及当前读者的赞/收藏状态，不公开收藏总数。匿名读者不能看到他人的待审核回复。
- 独立话题帖可在预览中显式指定 `species`；不允许覆盖私人观察、外部来源或地图记录的物种。客户端仅在服务器声明 `features.speciesPosts` 时发送该字段。
- 新服务声明 `features.threadedReplies`。旧服务仍可普通回复、点赞、收藏和阅读；指定楼层回复及准确计数须部署新业务服务后验收。

## Qwen 部署交接

出行顾问已有真实业务路由及 `qwen-plus` 编排。文字写作现在默认使用 `BIRD_BUSINESS_QWEN_TEXT_MODEL=qwen-plus`，勾选照片时保留 `BIRD_BUSINESS_QWEN_MODEL=qwen3-vl-plus`；两者均可由管理员配置。只提交用户在界面明确选择的资料。

服务端变量见 `backend/.env.example`（团队仓库）；出行使用 `BIRD_BUSINESS_TRIP_API_KEY`、`TRIP_WORKSPACE`、`TRIP_MODEL`，写作使用 `BIRD_BUSINESS_QWEN_API_KEY`、`QWEN_BASE_URL` 及两个模型设置。已有部署脚本现在加载可选 `/etc/bird-assistant/writing.env`，该文件由管理员保管并设置0600权限；未提供文件时原有部署仍能启动。北京业务空间地址的模板为 `https://<workspace-id>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。不要从模型名推断地域或业务空间，按控制台核对；本轮没有执行真实调用或部署。

[阿里云官方兼容接口与地域说明](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。真实启用仍需服务器配置、正确的地域/业务空间和模型访问权限；不以离线模拟证明已启用。
