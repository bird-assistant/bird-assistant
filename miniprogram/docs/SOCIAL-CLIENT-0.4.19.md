# 0.4.19社交与媒体设计交接

本轮只做客户端与交互设计。既有服务端、CloudBase函数、传输、凭据和部署未改；服务器恢复另行处理。本轮未向业务服务发请求、调用模型或实际发送社交消息。

| 模块 | 客户端沿用既有合同的能力 | 后续需要服务器支持 |
| --- | --- | --- |
| 好友 | 可发现用户搜索、申请／同意／拒绝／撤回／移除、复制自己的鸟友号 | 申请附言、后续二维码／链接发现与更完整防滥用策略 |
| 私信 | 文字历史、发送／幂等重试、已读游标、屏蔽／举报、本机草稿与列表设置 | 私密附件、向发送者反馈已读、复合历史游标、实时投递与跨设备发件箱 |
| 群聊 | 建群、同意后入群、群主／成员、找成员、文字、邀请、退出／解散、本机群备注 | 共享群名／公告、管理员、移出成员、群主转让、权限修订号与审计 |
| 论坛 | 文字与楼中楼、引用草稿、长楼层展开、既有帖子互动与举报 | 图片回复、逐条回复点赞／举报、父回复撤回占位与更稳健分页 |
| 转发 | 明确选择好友／已加入群，发送公开帖ID引用，打开重新检查可见性 | 有版本的卡片消息类型、手帐／媒体引用与更完整撤回状态 |
| 通知 | 当前私信／回复／邀请列表；本机可恢复隐藏 | 跨设备读／隐藏状态、订阅通知与审核／提及推送 |

**不能把缺少接口的动作显示为成功。** 本机备注不改变共享群名；“本机不提示未读”不等于取消推送。当前举报接口支持公开帖子、收到的私信、可见群消息，尚不支持单独指定某条论坛回复。

## 群权限建议（设计预览，待讨论）

群主可维护群名／公告、邀请、任免管理员、移出成员、转让与解散；管理员可维护名称／公告、邀请和移出普通成员，不能任免管理员或操作群主；普通成员可查看与退出。邀请必须由对方接受，收到邀请不提前获得历史。群主转让需已加入且合格的接收者确认，并始终保持一位群主。

未来变更需要服务端在同一事务内验证角色、成员修订号、操作标识并记录最少审计信息。失效权限不能继续按旧“群主”界面执行。被移出后应停止后续授权读取；已收到的消息保留规则需另行决定，不能宣称可抹去截图或已下载文件。

## 回复、图片与转发

引用保留稳定的回复ID和根楼层ID，展示原作者；不无限缩窄子楼层。父楼层撤回或被审核移除时保留不含敏感正文的占位，避免后续回复跳进无关楼层。设计预览中的“最多4张图片”是供反馈的提议，尚未上线。

保存草稿、上传、提交、审核、公开分别显示状态。上传完成不等于消息送达或回复审核通过。成功上传后使用媒体ID和稳定操作标识；消息体不永久保存本机路径或临时签名URL。失败保留文字与图片，重试避免重复。删除草稿附件不应删除仍被手帐／观察引用的原图。图片单独回复、部分上传失败和父楼层撤回的处理需后续合同明确。

当前转发只用既有文字接口封装内部公开内容ID与有限标题；不执行消息中的外链。旧客户端会看到普通文字封装。打开卡片走正常鉴权和可见性，原帖撤回后不复制成另一份公开快照。未来消息卡片应继续采用引用方式。

## 数据与缓存去向

| 内容 | 当前状态 | 后续云接入建议 |
| --- | --- | --- |
| 本机观察／手帐原图 | 既有持久文件，不随预览缓存清理 | 由用户选择上传；保留原件、所有权与导出，不自动公开 |
| 随手记／未发送私信／回复 | 本机笔记或按账号隔离的草稿 | 先决定同步与冲突策略，再宣称跨设备保存 |
| 手帐缩略图 | 既有可再生缓存，清理时保护被引用文件 | 带渲染版本重新生成 |
| 公开图鉴参考图 | 新增32张／16 MiB缓存；7天内优先本机，断网最多30天匹配来源回退 | 公开衍生图／CDN，继续保留作者、许可与换图标识 |
| 公开鸟讯／论坛图 | 既有公开路由；本轮不新增持久缓存 | 审核可见后提供尺寸合适的缩略图与内容版本，不在列表预取全尺寸原图 |
| 私信／群聊附件 | 本轮未新增 | 私密对象，验证双方／成员权限，限时读取；退群后停止后续授权 |
| 转发帖子 | ID与标题，不复制照片字节 | 打开重新检查可见性，必要时显示撤回占位 |

CloudBase应复用既有账号与权限，不建立平行的“云好友”身份。媒体所有权和对象读取范围必须由服务器验证；不得在客户端或永久分享链接中塞入凭据。公开副本默认去掉精确EXIF／位置，除非用户明确选择。切换传输、回滚和清理缓存均保留本机笔记与原件。

[可操作设计预览](design/social-controls-0419.html)含示例群角色、群名／公告、成员操作和图片回复，不联网。资料库／鸟讯布局参考了[eBird官方探索说明](https://support.ebird.org/en/support/solutions/articles/48001255128-find-birds-with-ebird)及[iNaturalist官方搜索说明](https://help.inaturalist.org/en/support/solutions/articles/151000169670-how-to-search-inaturalist-observations)，没有复制第三方画作或界面代码。原有[CloudBase准备](CLOUDBASE-0.4.17.md)保持未启用，待后续恢复服务器时重新核验。
