# 地图、导航与摄影交互修复 · 0.4.4

2026-11-25 · [English](en/NATIVE-INTERACTION-0.4.4.md)

0.4.3 的源码测试通过，但用户的微信截图与操作反馈明确表明：缩放仍需拖动才刷新、聚合重叠、下拉没有预期动画，且跨页访问后链接失效。旧记录保留为历史测试证据，不作为原生验收通过。此次优先处理可用性，再调整界面；范围对应 SRS MAP-01/02、COM-02、ID-01、LIVE-01。

| 问题 | 当前实现与证据 |
| --- | --- |
| 导航多次后无响应 | 旧调用持续 `navigateTo`，无失败提示，能耗尽微信十层页面栈。统一导航复用已在栈中的只读详情，深链到九层时替换当前只读页，给事件通道选择器保留一层；保留编辑页、未发送回复/私信。失败有提示且无永久锁。回归连续访问120次、失败后重试、未发送文字及选择器回传 |
| 隐藏原生组件 | 地图隐藏时移除原生地图与覆盖层，取消视野观察、请求代次和计时器；回来后恢复最后视野并重新挂载。相机原有暂停/释放链保留 |
| 缩放不刷新 | 优先采用 `regionchange` 报告的 scale/region/center，兼容顶层和 detail 的 begin/end。无 begin/无拖动也刷新；可见时240ms观察原生视野，手势期间原采样保留。原生回调1800ms未返回会结束本次读取，可重试。旧网络响应不能覆盖新视野；相同失败查询不会被自动观察反复重试 |
| 圆点重叠 | 服务端网格后增加墨卡托屏幕距离聚合。40px圆点保留4px间距；每次从原服务端分组重新计算，合并保留总数与地理范围，放大可重新分开。禁用地图旋转/俯视以匹配投影。相同坐标的记录仍合并，不伪造散开的位置。单记录近景转针保留；大计数显示实际数字 |
| 列表底部与排序 | 抽屉外壳到底部Tab边界，保留半透明面板；末端42px向上渐隐，内容尾留滚动余量，24px透明页脚保留原生署名。未隐藏腾讯标识，也未声称核实了隐藏授权。顶部说明「收录时间倒序 · 右侧为观察日期」。实际查询是 created DESC、id DESC；不是鸟名排序，也不是按右侧日期排序 |
| 展开箭头像打字 | 列表与变焦采用绘制的细线箭头及转动过渡，替换⌃/⌄字符。抽屉关闭改用细线交叉 |
| 下拉无飞鸟 | 信息流改为有界 scroll-view 自定义 refresher，拉动时显示三鸟，达到阈值提示松开，刷新时飞行动画；结束、隐藏、过期请求、失败均释放状态。保留刷新按钮、分页、重试和减少动态效果设置。页面JSON改变，需完整编译一次 |
| 相同照片的两篇帖子 | 只读核对当前公共API：11月24日18:06的帖子有日期、设备和关联地图副本；17:21的另一帖子无上述共享字段。它们是不同发布ID。未删除或按照片去重。界面区分发布时间、观察日期、讨论帖和地图副本；缺少副本时解释未关联 |
| 关联跳转含义 | 同一次观察可独立发布为讨论帖和地图鸟讯，时间、字段、审核分别独立。按钮改为「此观察的地图副本 / 此观察的讨论帖」。地图跳转：作者从讨论帖可通过已有ownedSighting引用读取自己的私人原始点并用17级定位；隐藏页面与过期回包不能触发跳转。出行顾问的原生中心回调有截止时间，离页后不再跳转。私人原始点用17级；约一公里公开网格13级，其他公开区域11级，并标明不是精确拍摄点。公共API未提供原始坐标时不猜测或绕过脱敏 |
| 摄影信息不足 | 原有共享EXIF卡扩展镜头、原图尺寸、白平衡、EV、测光、闪光等；图片加载后另标显示副本尺寸。照片上传白名单增加可用的标准EXIF，不读取GPS、设备序列号或厂商MakerNote来猜AF模式 |
| 专业相机手填参数 | 发帖/预览有可选摄影表单：机身、镜头、原图尺寸、ISO、快门、光圈、焦距、AF、AWB、EV、测光、光线、闪光。随草稿保存、预览保留。作者填写与文件读取分卡展示；缺少参数保持缺少 |
| 旧业务服务兼容 | 可选参数以明确标源的可读正文尾注传输，新客户端展示为卡片，旧客户端仍能阅读。上传文件参数仅在勾选共享时加入；不向旧预览API发送不支持的新JSON字段。正文与参数合计2000字上限先校验，失败保留草稿。后端新增独立讨论照片的共享参数预览；部署前仍可使用兼容尾注 |
| 识别控件占位 | 默认两个独立紧凑柄：变焦和画面/声音线索。轻触或上下滑动开合，短时渐隐/位移；录制、实时识别状态仍可见。开启的变焦保留实际倍率回报、3.5×快捷、横向刻度和微调；快门/导入/复核始终可用 |

## 验证与限制

- 客户端 `npm run verify`：153通过；配置、资源、WXML闭合、事件绑定、原生TypeScript兼容检查及业务行为回归。新组件也纳入源码检查。
- 后端本地：467通过、55跳过，覆盖率85.36%；变动相关社区测试17通过；Ruff通过。本地Python3.12的开发依赖环境用于验证，未改部署锁；目标锁环境由本头CI重新检查。
- 320/390/768宽、九种源码布局投影；[投影图](design/interface-0.4.4.png)与边界记录可再生成。使用原创示例图；打印投影不证明原生组件层级、触控、安全区或机型行为。
- 微信模拟器/真机需复核：只捏合不拖动的分裂/合并；重复进入详情至少20次；切换各Tab后操作；实际下拉/松开；稀疏EXIF与手填参数；摄影点精度；两个相机模块开合。先完整编译使页面JSON生效，勿将旧热重载状态作为新版本结果。
- 控制台的原生SDK鉴权/网络错误、canary提示、预加载与worker诊断未被隐藏，也没有以这些改动声称修好鉴权。
- Qwen配置与端到端、真实发帖/回复审核、统一云端部署、更多设备适配继续排后。保留后续淡入/淡出、轻移、溶解等视觉方向；当前仅使用短、小且可减少动态效果的过渡。手帐继续暂缓细化。
