# 0.4.13 体验版联调交接

2026-11-27。本次把完整小程序工程同步到团队当前 main 的独立 PR；不自动合并或上传体验版。工程入口是仓库内的 **miniprogram/**（外层，包含 package.json），实际打包根是下一层 miniprogram/。

## 本轮变化

- 照片写作打开时仍为空且不自动请求。有关联照片时，点击「生成写作建议」可直接采用简短、自然、只描述可见细节的默认要求；自己填写的要求优先。没有照片、可改写文字或要求时，才提示补充素材。
- 「新增文字框／所选文本框／页首概述」旁说明影响范围；生成后仍可切换目的地，应用前显示确认摘要，手帐名称不变。
- 编辑器直接提供「AI建议记录」入口。记录仅属于当前手帐／帖子草稿，成功生成后保存；旧版本未保存的结果不能补回。载入不会再次生成或自动应用。
- 共享底部面板按实际内容测量：短内容收缩，长内容按窗口限高后在内部滚动。覆盖手帐AI、建议记录、裁剪、图层、版式、论坛写作及手帐选择和示例地点面板。原生地图组件及其余弹层继续按 X01–X03 做整体空间检查，不把本轮描述成全部界面验收完成。
- 手帐牌组展示当前整页构图，包括文字、照片、纸张和装饰；只投影当前及相邻作品，不把编辑历史传给渲染层。失效缩略图有重复事件保护。缩减牌组下方多余留白。
- 帖子本来就可添加最多9张照片／手帐成品（其中手帐最多3份）；「4份」是单次AI参考上限。本轮明确区分，保持现有网关兼容。
- 启动日志同步为0.4.13；依赖和写作助手服务端无变化。

## 更新与快速冒烟

新克隆工程：`npm ci` → `npm run setup` → `npm run verify`。已有工程运行setup会保留AppID。不要清除本机手帐、草稿和媒体。已有写作助手终端继续运行，无须重启／重新输入密钥。

1. Compile后核对启动日志0.4.13，确认无WXML／WXSS／TS编译错误。
2. 打开手帐牌组，确认封面含文字和排版；左右滑动、进入并返回，作品内容与名称不变。
3. 编辑器进入「AI建议记录」：空列表为短面板；有记录时可滚动，关闭后仍能编辑。论坛空记录也应收缩。
4. 打开照片AI：输入为空，没有自动生成。可选择一次有用的生成：选一张自己的照片、留空、点击生成；预览后切换新增文字框／页首概述，核对目标后再应用。此步会消耗用户自己的模型额度。
5. 模拟器检查窄手机、刘海长屏及Android；再由用户选择上传体验版，在自己和朋友手机记录机型／系统／微信版本并检查键盘、安全区、遮挡、滚动和原生权限。
