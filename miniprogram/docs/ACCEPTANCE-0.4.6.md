# 交互修复、地点建议与验收顺序 · 0.4.6

2026-11-25 · [English](en/ACCEPTANCE-0.4.6.md)

以本轮用户截图与反馈为需求；0.4.5 的固定搜索高度、单张素材选择和联动灰闪未通过验收。源码可运行不等于微信真机已验收。

## 当前行为

- 地图抽屉标题/条数固定从顶部排布，折叠只收掉排序说明和列表，保留同一标题基线。搜索结果紧接工具栏，按实际数量显示一至三行，每行44px；更多内容滚动，背景半透明。地图底部26px使用与底栏衔接的不透明底面；不保留透明署名缝。地图框体不随抽屉开合缩放，中心识别圆钮仍在应用浮层之上。原生层级和边距需用用户设备复核。
- 鸟种地点有地图参考点时默认最近优先；距离相同按最新观察日期。也可选最新优先，同日按距离；没有参考点时明确使用最新，不主动请求定位。服务端在分页前排序，返回至地图中心的大致直线距离。区域内鸟讯按观察日期倒序，同日再按收录时间和稳定ID；旧接口仍明确标注收录排序，不伪装距离排序已经生效。
- 补充宁夏、广西、新疆等已知来源别名；未知地名保留原文。只翻译识别到的行政区名称。
- 鸟种图鉴/地点/讨论页签不依赖另一栏请求成功；地点与讨论分别处理失败。普通图鉴对比不再无条件创建事件通道，深层只读导航可使用已有栈恢复。页签增加明确的前景层；实际点击故障仍需原生复测。
- 讨论列表与帖子详情的赞/收藏按“帖子＋动作”独立锁定，独立更新已确认字段；允许另一动作同时提交，反序响应不覆盖另一动作。移除共用 disabled 引起的双按钮灰闪，点击不冒泡到父卡片。失败保留上次确认状态。总体动效不在本轮扩张。
- 照片参数卡仅在存在文件/手填参数时显示翻面提示；无参数照片不再假装可翻，轻点可得到缺参数反馈。放大按钮独立，显示副本尺寸不冒充原件EXIF。
- 识别线索展开区测量内容高度，空/短说明不再强制占100px；长候选区有上限并滚动。相机、缩放和线索收放保持独立。
- 导入照片/音频默认多选；边框代表本次模式真正勾选的文件，预览另有入口。逐份分析，结果/错误留在各卡；一份失败不吞掉后续素材，取消/离页不再启动队列后续上传。音频卡显示原文件名、截断、大小和可用时长；名称保存到本机记录并在回听入口保留。视频/示例不冒充可识别照片。声音和组合模式仍在上传前检查音频provider，未接入时保留全部素材。

## 出行建议和记录

Qwen提示与严格输出校验增加地点级 `visits`：为什么去、优先找什么生境、留意线索、时间/天气调整、资料限制。引用编号只在协议里使用；文字中的A/P编号经已知地点表展开，未知编号拒绝。回复提供 `referenceMap`，命名公园与公开网格分别点选地图，公园参考点不冒充入口/鸟类拍摄点。旧服务文字只展开已知来源名称，不按卡片下标猜A1坐标。

近一年获准公开的地图鸟讯、图鉴生境、逐时天气继续作为证据；增加颐和园/圆明园地点名录，以及北京五处公园的简短、有日期与链接的公共景观/冬季资料。来自[北京市园林绿化局](https://yllhj.beijing.gov.cn/ztxx/anz/anzxd/202510/t20251013_4221720.shtml)、[颐和园景观资料](https://yllhj.beijing.gov.cn/ztxx/kpjd/202312/t20231222_3508035.shtml)及[国家林草局调查报道](https://www.forestry.gov.cn/c/www/dzbhdt/636488.jhtml)。历史资料不表示当天鸟况；其他城市没有资料时用图鉴和明确标为条件的一般观察建议，不编造当地芦苇、岸向、人流或巢位。同十公里网格只支持区域背景，不证明鸟在该公园内。现有公开地图记录已包括获准发布的本地贡献；论坛正文/其他社区的检索与质量排序仍属后续工作。

“我的→观鸟咨询记录”保留当前社区账号在本机的最近20次咨询、每次最近6轮，保存完整地点卡和条件，可重进查看/追问。原会话约一小时失效后，新提问开启新服务端对话；旧答案保留并标明时效。旧日期不被作为新行程日期。退出/换号后隐藏前账号内容，迟到回答不能写入另一个账号；存储损坏或写失败明确提示，不覆盖旧资料。这是本机持久化，尚无跨设备云同步；新版本以前已关闭的页面输出无法凭空恢复。
