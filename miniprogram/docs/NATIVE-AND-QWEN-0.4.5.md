# 原生交互与照片手帐 · 0.4.5

2026-11-25 · [English](en/NATIVE-AND-QWEN-0.4.5.md)

本轮以用户的 0.4.4 截图与反馈为依据。0.4.4 的关闭图标、透明署名底条、搜索浮层位置、首次圆点点击，以及照片导入呈现未通过用户验收。旧版记录保留历史含义，以本说明为当前交接。

## 当前实现

- 地图观察抽屉在手机上横向铺满，直接接到底栏边界；底部不再保留透明署名条。主体仍半透明，最下方不透明，内容向下渐隐。原生地图不因抽屉开合而调整高度。关闭、清空和搜索关闭使用已有的完整 PNG 图标，避开微信 button 原生伪元素的冲突。
- 搜索结果紧接整个搜索/筛选工具栏的下边界，上边为直角、下边圆角。可见 Tab 栏层级 1000，高于应用内浮层；中央识别圆钮在 Tab 内位于最上层。专注编辑页仍按已有规则隐藏 Tab。
- 地图不再每次刷新都分配全新 marker ID；相同分组保持 ID，保留有界的旧目标以接收迟到回调，兼容字符串形式的原生 ID，省略内容相同的 marker setData。首次点击即打开对应记录；有范围的分组同时使用原生 includePoints 聚焦，兼容回退路径。离页回调不能重新打开列表。只缩放时的合并/拆分与计数守恒沿用 0.4.4 计算，原生逐帧行为仍需手机验证。
- “此观察的地图副本”改为“查看观察详情”，反向入口为“返回讨论帖”。点赞、收藏、回复和嵌套回复只在讨论帖展示，观察详情保留地点、来源、举报及返回原讨论的入口。未删除已有讨论或历史回复。
- 照片轻点翻到摄影参数面，底图淡化；再次轻点返回。文件参数与作者填写分别标注；支持 ISO、焦距、光圈、快门、镜头、白平衡、EV、对焦等已有允许字段。无可用参数时提示，放大查看为独立按钮。显示副本分辨率不能冒充原图尺寸，未知信息不补造。修复 photo-editor 的组件 WXSS 标签选择器警告。
- 对已知中文省级行政区/直辖市的英文来源标签使用中文显示，例如北京、四川、浙江、上海、湖北；未识别的地名保留来源原文。覆盖地图记录、鸟种出现地点、观察详情和出行地点卡。
- 去掉“发帖”旁重复的刷新按钮，保留自定义下拉飞鸟与失败重试。变焦标签保持横排；现有变焦、线索模块独立收放保留。
- 导入页直接显示照片/声音小卡片与选择状态，有独立“开始识别”，不再只有数量并要求先进入复核页。可选仅照片、仅声音、照片＋声音；单次选择一张照片/一段声音。照片沿现有真实上传路径；声音仅在显式安装支持 audio 的 provider 后启用。组合结果分别展示，不把两种分数混合为置信概率。当前尚未安装音频网络 provider；声音/组合会在任何上传前明确提示，素材保留。视频仍可私人保留，未假装已接入视频分析。
- 姓名头像按名称即时显示：英文开头取一个大写首字母，中文开头取一到两个汉字。用于本机资料编辑和社区账号头像，不再固定显示 B；上传/裁剪原有路径保留。

## Qwen 与队友的照片生成手帐需求

出行服务已有真实 qwen-plus 调用，本轮不把它说成尚未接入。新服务提示词要求先给简短结论，再输出经校验的 brief：推荐理由、可留意的鸟、准备事项、关键不确定性。地点/来源编号和时段继续校验；历史记录不能写成今日必见。客户端渲染为要点卡、时间表、可收起来源与完整说明。旧服务没有 brief 时，也按完整句子分段，避免一整墙文本。新 brief 需部署本轮后端后才出现。

地点卡提供“羽迹地图”与“打开区域位置”；公园可打开具体公园点。使用 wx.openLocation 进入微信位置页，其后支持哪些导航应用由微信和手机决定，未虚构花瓣/高德/百度等任意应用选择器。鸟讯网格中心明确为约十公里公开区域，不冒充精确拍摄点或公园入口。接口文档见 [微信位置页](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.openLocation.html)。

手帐设置增加“根据照片生成手帐”：选择自己的 1–4 张照片，点击前说明将发送压缩副本和主动选入的备注；先生成可编辑本地稿，再通过已有团队写作网关请求标题、短文和版式建议。建议先预览，再选择只应用文字或连同版式应用，支持撤销；关闭、隐藏或修改要求会作废图片保存期间的准备工作，避免关闭后迟到上传；手帐已经修改时拒绝旧建议。照片原件保留，不把示例插画当成真实观察，不推断鸟名、GPS、时间、天气或亲历心情。

文字请求沿服务端 qwen-plus 配置；有图请求沿服务端配置的视觉模型（当前默认 qwen3-vl-plus）。本轮没有将图片发给纯文字模型。密钥仍只在服务端，未复用聊天中曾出现的凭证，未在本轮工具中进行付费模型调用或云端部署。现有 JSON Object 模式加服务端严格校验继续使用，不假定部署中的模型支持 JSON Schema 模式。[百炼结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。
