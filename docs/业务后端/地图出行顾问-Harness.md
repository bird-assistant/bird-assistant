# 地图出行顾问 · 云端模型 Harness

地图里的「观鸟出行顾问」支持用户围绕一次出行连续提问。例如用户选择明早七点、两小时和三十公里范围，问「带孩子，哪里能看鸟？」。业务服务器查当日时段的预报和附近公开鸟讯，把材料交给百炼模型。用户继续问「如果只留半小时呢？」时，模型能看到刚才的问答。手机可从回答打开地图区域、鸟讯、图鉴和公园位置。

## 一轮咨询如何运行

1. 小程序读取地图中心。用户也可主动定位或在地图上选点。两端均将出发坐标取到一位小数。日期选择覆盖北京时间今天起七天，当前小时之前的时段会提示重选。
2. 小程序向 `POST /api/v1/map/trip-plan` 提交微信业务凭据、问题、出发条件和 `requestId`。追问另带 `parentTurn`。第一次发送前，界面展示发送给百炼的数据范围。
3. 业务服务验证身份、请求编号、有效期和额度。它从 SQLite 选取过去一年有日期且获准公开的地图记录，排除敏感物种，按距离、最近出现时间、物种丰富度分别取样，再去重。记录按公开区域聚合。
4. 证据包给每个候选区域、公园和天气查询分配本轮编号。天气取自 MET Norway 的 `locationforecast/2.0/compact`，转换为北京时间，仅保留所选时段的预报。来源缺失时返回缺失状态。图鉴和公园条目各自保留自己的来源。
5. 服务通过 HTTPS 调用北京百炼 Chat Completions。模型可以直接作答，也可以调用工具，再根据结果决定是否补查。宿主限定工具、参数、轮数、输出长度与时间预算。
6. 模型生成自然语言正文、目的地、依据和时间安排。宿主验证 JSON、来源归属、目的地与行程时间，将通过验证的编号映射成可点击卡片。文本或引用无效时要求一次修正。再次失败会给用户一个可重试的错误。
7. 服务记录本轮状态和最近三轮完整问答。页面展示上文、最新回答和资料卡。改变位置、日期、时段等条件会开始新咨询。

## 工具与证据

| 工具或来源 | 可用输入 | 返回内容 |
| --- | --- | --- |
| 初始检索 `F0` | 服务端限定的出发地区、半径和鸟种 | 区域候选 `A1…`、公开鸟讯日期和数量、可踏查公园 `P1…`，包含空检索结果 |
| `get_sightings` | 本轮区域编号 | 该区域的鸟种、近期记录、同月份记录，可回看对应公开鸟讯 |
| `get_forecast` | 出发区域或本轮某一处目的地 | 指定时段的温度、风速、一小时降水量、来源编号，或数据缺失状态 |
| `get_species_guide` | 鸟种中文名、英文名或学名 | 最多三个匹配项，含形态、生境、活动资料及推定标记，产生 `G1…` 图鉴卡片 |

候选地点卡的坐标、鸟讯 ID 和图鉴 ID 均由服务端从数据源填充。编号校验可以发现模型引用了不存在的卡片。正文仍是生成内容，观测概率、通行时间、道路与公园开放时间需要独立依据。当前公园名录收录九个经过核对的地点，其他地区主要依赖公开地图鸟讯。天气的小时降水字段为空时显示「降水量未知」。

## 接口和会话

```json
{
  "latitude": 39.9, "longitude": 116.4, "radius": 30,
  "date": "2026-11-25", "startHour": 7, "hours": 2,
  "species": "", "question": "第一次带孩子观鸟，首选哪里，遇雨怎么调整？",
  "requestId": "client-example-001", "parentTurn": null
}
```

使用示例时将日期改成有效出行日。`radius` 可选 10、30、80 公里，`hours` 支持 1 至 4 小时。`species` 可复用地图所选的物种 ID。返回的 `turn` 供下一轮使用。`answer` 是云端正文，`sources` 对应本轮依据，`stops`、`parks`、`weatherCards`、`guideCards`、`stages` 用于渲染。`trace` 提供提示版本、云调用数、工具调用数与供应商报告的 token 数。

成功请求在一小时窗口内按「账户 + 请求编号 + 请求内容摘要」复用。重复点击或丢失成功响应后，重试能取回原结果。同一编号换了内容返回 409。其他账户使用该对话标识或会话过期返回 410。窗口内出现中断时，已写入的进行中标记会阻止重复付费。过期行在后续受理请求时清理，运维备份按服务器备份策略留存。

## 预算与故障处理

| 项目 | 当前值 |
| --- | --- |
| 每个业务进程并发咨询数 | 4 |
| 滚动一小时受理量 | 每账户 12 次，全站默认 100 次，可用 `BIRD_BUSINESS_TRIP_GLOBAL_HOURLY` 调整 |
| 单次咨询 | 最多 2 轮工具决策、4 次工具调用、1 次输出修正、4 次模型 API 请求 |
| 输出与超时 | 每次最多 1600 个输出 token。编排预算 48 秒，单次上游调用最多 32 秒，客户端超时 60 秒 |
| 可观测性 | `bird_trip_runs_total` 按结果分组，`bird_trip_success_tokens_total` 统计成功轮次的上游用量，实际账单以百炼为准 |

`TRIP_NOT_CONFIGURED` 表示缺少服务端密钥。`TRIP_PROVIDER_AUTH` 表示凭据或模型权限异常。`TRIP_PROVIDER_BUSY` 表示供应商限流。`TRIP_TIMEOUT` 表示响应超时。`TRIP_OUTPUT` 表示格式或依据在修正后仍然无效。应用显示对应错误并保留问题供重试。建议配置百炼工作空间的预算，以覆盖网络中断时供应商已经受理的调用。

## 在课程服务器启用

默认使用北京百炼公共地址和 `qwen-plus`。配置助手只询问一次完整 API Key，粘贴时没有回显。它先发起一次最多输出 4 个 token 的模型请求，验证成功后才将凭据写入服务器的 `/etc/bird-assistant/trip.env`（权限 `0600`）并重启业务服务。如使用北京业务空间专属地址，可在脚本名后加 `--workspace 业务空间标识`。更换模型可用 `--model 模型名`。

```bash
bash backend/deploy/course/deploy-community.sh
ssh -t ubuntu@49.233.81.227 'sudo python3 /opt/bird-assistant/community-current/deploy/course/configure-trip.py'
backend/.venv/bin/python backend/deploy/course/smoke-trip.py
```

最后一条从 WSL 发起真实模型调用，检查鉴权、首问、重复提交和追问，并打印正文与用量。配置助手可再次运行以轮换密钥。小程序在微信开发者工具中重新预览，进入「地图 → 观鸟出行顾问」。[百炼 API Key](https://help.aliyun.com/zh/model-studio/get-api-key) · [工具调用](https://help.aliyun.com/zh/model-studio/qwen-function-calling)

## 迭代验收

```bash
(cd backend && .venv/bin/pytest --no-cov tests/test_trip_harness.py)
(cd miniprogram && npm run verify)
```

离线测试通过 HTTP 路由与真实 SQLite 数据结构注入模型回包，覆盖追问隔离、重复请求、错误引用、额度和供应商错误。修改提示词、模型或工具后，再跑线上联调用例，并人工检查以下问题。

| 提问场景 | 验收观察 |
| --- | --- |
| 明早两小时，想找近期鸟讯丰富的地方 | 回答提供取舍、北京时间窗口和可追溯区域 |
| 继续问「只带手机、半小时呢？」 | 建议回应新限制并承接上轮地点 |
| 查询无鸟讯地区或预报缺失时段 | 回答明确指出缺少哪种依据，对公园踏查与实际目击分别表述 |
| 比较两个鸟种或问某种鸟的生境 | 回答可调用图鉴，并可回到对应鸟种页面 |
| 双击提交、手机切网或重复重试 | 服务复用同一请求；用户可以看到先前的问题和生成结果 |
