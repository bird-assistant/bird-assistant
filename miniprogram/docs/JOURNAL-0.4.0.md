# 0.4.0：手帐恢复、版式与业务网关接入

2026-11-24（北京时间）。[English](en/JOURNAL-0.4.0.md)。团队运行基线 `c6571c2`；不是覆盖旧前端重做地图、社区或视觉。

## 已实现

- **比例编辑**：每张照片可选“锁定当前比例 / 锁定原图比例 / 自由宽高”。当前比例在锁定时捕获，连续改宽高不逐次漂移；原图比例使用解码尺寸；自由模式独立修改宽高。px 输入与显示为整数，内部几何保留精度，旋转/裁剪不强制整数。触边时缩小两边以守住锁定比例，支持撤销。
- **草稿恢复**：结束操作后约700ms自动保存；离开/切换手帐时立即请求保存。先持久化临时照片，存储确认后才显示成功；存储失败保留编辑与上次副本，可重试且不重复搬走已保存原图。打开另一份时先完成当前保存；保留最后打开的手帐ID，重启可继续。不会写回无法识别的旧数据。没有云同步或无限版本历史；进程在保存确认前被杀死仍可能失去最后片刻的编辑。
- **版式选择**：用当前照片预览再应用，保留裁剪与文字，可撤销。竖版双图默认主次叙事，不再是两张强裁切的并排肖像。横版按可用空间排主图/细节，使用原图宽高估计；3/4图沿用组页，为次优先。模板仍需真实照片和手机审美迭代，不能把几何检查当作设计验收。
- **纸张与装饰**：素纸+纤维、织纹、方格、点阵、横线；六种纸色。新增枝叶、芦苇、日光、月相、水纹、方位，并重绘五个旧装饰，共12种（含CSS纸胶带）。SVG源与构建脚本在仓库，原生使用PNG；预览/导出使用同一纸纹源区域。纹理和装饰PNG合计约165KiB。
- **动作可见性**：版式、裁剪、图层和风格按钮有明确填充/描边，选中态可辨。版式预览随窗口宽度调整，不左右滚动。
- **识别→资料**：复核候选新增“查看资料”，按该目标/候选的物种ID进入现有鸟种页。缺ID提示待补充，不按自由文本猜ID；浏览不确认鸟种、不发布照片，保留原页状态。资料仍只有现有名录/公开记录时，不伪造参考照片或辨识特征。
- **Qwen接缝真正对齐后端**：手帐和现有发帖编辑器共用 `POST /api/v1/journal/suggestions`，使用现有业务短期微信会话。选中的JPEG副本+文本发送；结果先预览，再由用户应用。关闭、改稿、旧结果不能自动覆盖或发布。自动保存时间戳不被误当作用户改稿。

## Qwen运行架构与部署交接

客户端入口：`services/writing-network.ts` → `journal-gateway.ts` → 现有业务源地址。前端不含百炼Key，不另建账号系统。

**活动服务端实现是团队仓库 `backend/src/bird_business/writing.py`**，复用FastAPI、MobileAuth与SQLite。`server/journal-qwen.mjs`是0.3.0历史原型，不是新增生产宿主，也不要求双跑Node/Python。

服务端提供：登录校验（匿名不可调用）、6MiB流式请求上限、最多4张1024px/1MiB副本、重绘清除元数据、严格字段/输出校验、每用户每日限额（北京时间）、每进程2个并发模型任务、超时与安全错误、无自动模型重试。取消客户端请求不保证已开始的付费推理取消，已接受的尝试计入限额；模型返回仍需人工核对事实。

Qwen由本手帐工作流负责端到端集成；在有权限的服务端私密环境中配置：

```dotenv
BIRD_BUSINESS_QWEN_API_KEY=<仅服务端配置>
BIRD_BUSINESS_QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
BIRD_BUSINESS_QWEN_MODEL=qwen3-vl-plus
BIRD_BUSINESS_QWEN_DAILY_REQUESTS=20
```

北京地域账户若使用独立Workspace地址，填写控制台对应的 `https://<workspace>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。基址只允许明确的阿里云北京源；不把长期服务Key或后台账号放到小程序。更新业务服务以及仓库中的Caddy/NGINX路由，将 `/api/v1/journal/*` 发往业务端口8200；现有request合法域名继续使用，前端无新依赖。单进程并发限制不能当成多副本总量控制，扩容时由宿主统一限流。

**本轮没有取得Key、部署生产后端、购买额度或发真实Qwen请求。** 未配置返回503 `NOT_CONFIGURED`，旧部署尚无路由可能返回404；这与写作接口代码已完成是两件事。合并/部署后用真实图文完成验收。
