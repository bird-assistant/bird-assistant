- 「我的 → 本机备份与恢复」及设置页提供完整文件备份。收藏地点默认全选，手帐可分批勾选；包含文字、排版、当前照片和仍在撤销／重做历史内的照片原件，不压缩原图。

| 已经全部清除、且没有旧备份 | 本轮无法凭空恢复之前已删除的资料。 |

## 导出与恢复

1. 打开「我的 → 本机备份与恢复」，选择要包含的手帐，点击生成备份。每份最多64 MiB原照片，可分批；同一原图去重。缺少任何所需原图会明确失败，不生成貌似完整的残缺备份。
2. 点击「发送／另存备份文件」。建议发给文件传输助手，再在电脑下载保存，或另存到手机系统文件。**只生成在小程序内、或只看到发送成功，都不能证明已有微信外副本。** 页面会保留该提示。
3. 在需要恢复的设备把 `.birdbackup` 文件放到微信会话中，点「选择备份文件」。先检查地点、手帐、照片数量与日期；确认后逐张校验，全部完成再提交。
4. 保留现有资料；相同坐标的收藏地点保留当前记录。手帐ID冲突时新增「恢复副本」，不覆盖新编辑；撤销历史ID同时重写。失败／取消仅删除本次临时恢复照片。

备份只包含收藏地点和所选手帐，不包含账号、社区书签、私信、随手记或其他本机记录。文件包含私人照片及地点，未加密；请保存在可信位置。备份／恢复不自动上传，也不请求登录或业务服务。完整记录快照上限4 MiB；超限保留旧记录并提示，不自动淘汰原件。照片按256 KiB分块读写，避免把整份原图备份转成巨型base64字符串。
