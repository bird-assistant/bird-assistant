实现 #14：微信小程序地图、观察面板与位置确认

对应 #14。将 v0.5 的地图交互落到微信原生小程序：原生地图、地点搜索、范围/日期/鸟种筛选、公开记录聚合、私人标记、观察面板、详情 ID 跳转和位置确认。选点取消不改写原值；快速拖动、切筛选和搜索时丢弃过期响应。
