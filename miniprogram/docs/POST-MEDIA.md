# 帖子素材与草稿：0.4.7评阅候选

2026-11-26（北京时间）。[English](en/POST-MEDIA.md)

用户当前设备仍测试0.4.6。本页记录新增候选及后续建议，不表示已经上线；原有0.4.7识别修复继续保留。

## 本轮候选

- 发帖与信息流采用三列1:1缩略图，点击查看完整原图；方形只影响缩略图，不裁切用户文件。可移除单项、按照片填写参数；暂不加入像素编辑器。
- 一篇最多9张视觉附件，其中最多3份已保存手帐。手帐选择后用与编辑器相同的Canvas路径生成成品图，分享的是当时的快照，后续修改私人手帐不会改变帖子。手帐占用同一9张额度；不上传私人编辑文档或其全部原始素材。
- 多图从编辑、预览、上传、审核、信息流到详情保留顺序。详情可选择图片查看各自已分享的参数，现有图片翻面与放大入口保留。
- 摄影参数容器与输入行统一上下内边距，限制原生input高度；参数按单图记录，不套到整组图片。
- 草稿改为受管文件副本与事务清单，保留原始字节，不移动或压缩原图；重复保存重用已有副本，成功提交清单后只回收本草稿失去引用的受管文件。
- 文件额度不足或复制/写清单失败时回滚新副本，保留旧完整草稿；同时保留最新文字、参数与明确的缺图占位。不会报告整份已保存，也不清空其他观察、手帐或缓存。真实空间耗尽仍需恢复可用空间；不能承诺无空间时保存全部照片。
- 兼容旧v1单图草稿。新服务器能力未部署时，多图在上传前明确停止并保留编辑内容；旧单图发布协议继续可用，单份手帐可作为普通成品图发布。

## 配套服务器改动与部署顺序

`GET /api/v1/community/capabilities`返回postGallery版本及9/3额度；`Preview.gallery`逐项接收本人已上传media、类型、标签和作者填写参数。拒绝超过9图/3手帐、重复media、他人media、与旧cover冲突及地图/外部引用混用。

新`/publications/{id}/photos/{index}`与原cover路由沿用同样的已审核可见性；待审、退回、撤回内容不因多图路由被公开。每图只返回已同意分享的相机字段；下载仍是服务端去除原始EXIF/GPS的公开JPEG副本。网页及API审核可逐张查看，不能只审核封面。

先部署配套业务服务和审核静态资源，再体验多图客户端；不需要另建云函数、公开原始上传文件，或修改现有数据库表。当前工具没有部署、公开发帖、调用模型或使用网页后台口令。

## 暂保留的产品建议

1. 视频建议先限一段、10秒；音频建议先限一段、60秒。这是建议的产品额度，尚未作为微信平台限制或已实现能力。需补齐真实文件/时长校验、存储、转码、播放、审核和失败恢复，再开放入口。
2. 本轮增加独立公开照片/手帐保存按钮，下载脱敏副本，校验公开路由及相册权限、处理撤回与失败；仍需微信真机和downloadFile合法域名。视频/音频导出随完整发布链路实现。
3. 本机自动读取已进候选：JPEG/PNG/WebP/TIFF白名单、256 KiB读取上限、逐图参数和读取失败反馈；真实04图已正确提取。只读展示，不自动把文件字段当作者填写或观察GPS/日期；服务端继续独立提取。
