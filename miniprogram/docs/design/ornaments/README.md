# Original Yuji ornaments

Original geometric/botanical SVG paths authored for this project on2026-11-24. No third-party template/icon artwork is copied. PNG counterparts are used by the native mini-program so preview and export share assets; SVGs remain editable source outside the upload root.

Optional regeneration: install `cairosvg` and `pillow`, then run `python scripts/build-journal-assets.py` from the mini-program project. The same script deterministically builds the transparent900×1200 paper textures. New assets require neither a client library nor an image-generation API.
